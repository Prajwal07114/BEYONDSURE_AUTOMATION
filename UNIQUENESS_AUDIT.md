## Audit conclusion

No two templates share the same hero structure + section order + CTA
placement + visual composition combination. Every row differs from every
other row in at least three of the four dimensions, and most differ in all
four. **No duplicates found; no redesigns required.**

Notable deliberately-contrasted pairs (templates that could have collapsed
into "the same thing with different colors" if not designed carefully):

- **Limited-Time Offer vs Discount Campaign** -- both are percentage/price
  led promotions, but Offer uses a badge+urgency-bar+centered-number layout
  while Campaign uses a diagonal two-block split banner. Different DOM,
  different visual rhythm.
- **Product Spotlight vs Feature Focus** -- both foreground a single
  feature, but Spotlight uses a radial-gradient image band + side-by-side
  callouts, while Feature Focus uses oversized ghost numerals in a plain
  list. No shared structure.
- **Guide vs How It Works vs Service Explainer** -- all three are
  "steps," but Guide uses a numbered vertical list with a ToC strip,
  How It Works uses a horizontal timeline rail, and Service Explainer uses
  a vertical connector rail with an icon row above it. Three genuinely
  different step metaphors.
- **Premium Minimal vs Luxury Editorial vs Executive Brief** -- all three
  are "premium," but Minimal has no color band and a text-link CTA, Luxury
  Editorial has a dark/gold full-width band and a testimonial, and
  Executive Brief is a dense numbered-clause memo with no cards or
  whitespace luxury at all.
